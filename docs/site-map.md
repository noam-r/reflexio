# Reflexio: Documentation Site Map

This page defines the current documentation structure for Reflexio as a small linked knowledge base rather than a single long document.

## Purpose

Show the actual site structure, reading paths, and supporting pages for the current documentation set.

## Writing Model

Each page is designed to:
- answer one main question
- stand on its own
- stay short enough to scan
- connect to adjacent and related pages
- work as markdown-first content for static-site publishing
