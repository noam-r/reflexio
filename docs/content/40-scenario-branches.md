# Scenario Branches

This page defines the possible future paths explored during Prospective Reflection.

## Purpose

Explain how Reflexio modules model multiple plausible futures rather than treating one projected path as certain.

## Core Idea

A scenario branch is one plausible version of how a future event may unfold. Branches are the main unit of exploration inside the simulation sandbox. They allow Reflexio to compare alternative actions, possible responses from others, and likely emotional consequences across multiple futures.

This is what keeps the module grounded in preparation rather than prediction.

## Why Branches Matter

Future situations are uncertain. If Reflexio simulated only one imagined outcome, it would risk overconfidence and tunnel vision. Branches solve this by keeping multiple plausible paths visible.

They help the user distinguish between:
- what is likely
- what is feared
- what is hoped for
- what is avoidant
- what becomes possible with better framing

## Common Branch Types

A useful set of branches may include:
- best-case
- likely-case
- hard-but-manageable case
- feared case
- avoidance case
- improved-framing case

Not every simulation needs all of them, but this structure often helps expose distorted expectation and hidden tradeoffs.

## What a Branch Contains

A branch may include:
- proposed action or event setup
- projected outcome
- projected discrepancy
- projected appraisal
- projected emotional effect
- projected relational effect
- projected cost of the path
- projected benefit of the path

This makes branches comparable in a structured way.

## Why Branches Are Better Than Advice Alone

A single projected path often hides uncertainty. Branches make tradeoffs explicit.

For example, in a sensitive conversation:
- one branch may optimize honesty
- another may optimize immediate harmony
- another may optimize long-term self-respect
- another may avoid the issue entirely but increase later resentment

Seeing these branches helps the user make a more conscious choice.

## Example

If a user wants to discuss a sensitive issue with a partner, branches might include:
- direct but blunt wording
- vulnerable and collaborative wording
- postponement
- total avoidance

Each branch can then be compared not only by comfort, but by likely relational and emotional consequences.

## Design Rule

Scenario branches should represent plausible alternatives, not decorative variations of the same projected outcome.
