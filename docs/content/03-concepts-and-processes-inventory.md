# Concepts and Processes Inventory

This page lists the major concepts, processes, and structural topics that make up Reflexio. Each item should later receive its own page.

## Purpose

Provide a complete inventory of the framework before expanding each topic individually.

## Concepts

1. Self-State — the persistent global internal state of the system.  
2. Counterparty — the external actor the system interacts with.  
3. Relationship State — the persistent state describing how the system relates to a specific counterparty.  
4. Event — a discrete occurrence that can affect the system.  
5. Event History — the ordered record of events over time.  
6. Actual Outcome — what in fact occurred.  
7. Expectation — a structured anticipation of what will happen, what is wanted, or what should happen.  
8. Predictive Expectation — what the system thinks is likely to happen.  
9. Desired Outcome — what the system wants to happen.  
10. Deserved Outcome — what the system believes should happen.  
11. Expectation Confidence — how certain the system is that an expectation is correct.  
12. Expectation Importance — how meaningful the expectation is.  
13. Expectation Rigidity — how strongly the system holds to the expectation.  
14. Relationship Lens — the current relationship frame used to interpret counterparties and past events.  
15. Discrepancy — the gap between expectation and actual outcome.  
16. Predictive Discrepancy — the gap between what was expected and what occurred.  
17. Desire Discrepancy — the gap between what was wanted and what occurred.  
18. Normative Discrepancy — the gap between what should have happened and what occurred.  
19. Appraisal — the meaning-making interpretation applied to a discrepancy.  
20. Appraisal Dimensions — categories such as respect, rejection, threat, fairness, closeness, or repair.  
21. Emotional Impact — the immediate affective consequence of an appraised discrepancy.  
22. Emotion Ledger — the append-only record of emotionally meaningful impacts and adjustments.  
23. Ledger Entry — a single immutable record in the ledger.  
24. Entry Scope — the target of a ledger entry, such as self-state or relationship state.  
25. Entry Magnitude — the signed strength of an entry’s effect.  
26. Entry Provenance — where a ledger entry came from.  
27. State Resolver — the mechanism that derives current active state from ledger history.  
28. Active State — the present affective condition derived from the ledger.  
29. Structural State — longer-term learned changes that remain after immediate activation fades.  
30. Decay — reduction of an entry’s active contribution over time.  
31. Persistence — tendency of an effect to remain active.  
32. Reinforcement — strengthening of an existing pattern by later events or replay.  
33. Unresolvedness — degree to which an event remains unsettled.  
34. Reactivation Potential — degree to which an older event can become active again.  
35. Scar — a lasting structural effect left by past events.  
36. Repair — a process or event that softens or restores prior damage.  
37. Integration — process through which emotionally charged material becomes more coherent and less destabilizing.  
38. Insight — a new understanding that changes the meaning or significance of a prior event.  
39. Insight Event — a discrete event generated by reflection or replay.  
40. Reflective Adjustment — a bounded change to expectation, confidence, interpretation, or scope.  
41. Cross-Relationship Spillover — effects from one relationship influencing the general self-state and later interactions with others.  
42. Response Policy — the behavioral control layer that converts active state into communication style.  
43. Explainability — the system’s ability to account for why it feels or responds in a certain way.  
44. Auditability — the ability to trace states back to specific causes.
