# Executive Summary

This document proposes an explainable affective-processing architecture for an interactive system. The system maintains a persistent self-state and a persistent relationship state for each counterparty. Each interaction is recorded as an event and processed by comparing the system’s active expectations with the actual outcome. Emotional impact is generated by the discrepancy between what was expected, wanted, or believed should happen and what actually occurred. That discrepancy is then interpreted through an appraisal layer, producing changes in affect, relationship, and behavior.

Rather than overwriting internal state directly, the system records emotionally meaningful impacts in an append-only emotion ledger. Current state is derived from that ledger through a state resolver that accounts for time, persistence, reinforcement, unresolvedness, and repair. This makes the model auditable: the system can explain why it currently feels a certain way, which expectations made an event matter, and how specific events contributed to the present self-state or relationship state.

The architecture also includes asynchronous echo processing and structured reflection. Past events can be revisited under a changed relationship lens, allowing the system to generate insight events that soften, deepen, repair, or reorganize prior emotional impact without rewriting history. In this way, the model supports both continuity and reinterpretation: facts remain fixed, emotional records remain traceable, and current feeling remains a derived result of history, expectation, appraisal, and later reflection.
